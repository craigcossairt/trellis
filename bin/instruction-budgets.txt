# Byte budgets for the AGENTS.md files Codex loads.
# Read by bin/check-instruction-budgets.sh, which explains each directive.
#
# Raise a budget in a change that says what the new text is for. Moving
# rationale out of AGENTS.md into docs/ is the usual fix, not a bigger number.
# If you raise project_doc_max_bytes in ~/.codex/config.toml, raise `limit` to
# the same value here. If this project never runs Codex, delete this file and
# CI prints a skip instead.

# Codex's default project_doc_max_bytes.
limit 32768

# Any concatenation (root + a nested AGENTS.md) may use 90% of it, leaving room
# for a file to grow between checks.
share 90

# The root file's own budget is the whole limit: past it, Codex drops the tail.
file agents AGENTS.md 32768

# A nested AGENTS.md that Codex appends when started in its directory:
# file api services/api/AGENTS.md 8000
# sum agents api
